# Sustainability

The project applies sustainability to environmental impact, maintainability,
community health, and long-term public value.

## Requirements

- Prefer deterministic checks over model calls when both can answer the same
  question.
- Do not poll external projects unnecessarily.
- Cache stable public information when policy and freshness permit.
- Keep skills concise and load detailed references only when needed.
- Avoid new dependencies, services, and packages without a maintenance case.
- Avoid generating large speculative diffs or repeated review text.
- Give temporary downstream workarounds an owner and removal condition.
- Account for maintainer and contributor time as constrained resources.
- Do not claim measured environmental benefit without evidence and a dated
  method.

## Guidance status

The project considers the latest
[W3C Web Sustainability Guidelines](https://www.w3.org/TR/web-sustainability-guidelines/)
as informative guidance. As of 29 July 2026, WSG is a W3C Group Note Draft,
not a W3C Recommendation. This project must not misrepresent that status.
