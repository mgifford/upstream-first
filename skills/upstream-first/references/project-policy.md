# Project Policy Discovery

Inspect:

- `README`, `CONTRIBUTING`, `GOVERNANCE`, `CODE_OF_CONDUCT`, `SECURITY`,
  `SUPPORT`, license, and release documentation;
- `AGENTS.md`, bot rules, AI policies, and automation instructions;
- issue forms, pull-request templates, labels, and design-proposal processes;
- CLA, DCO, sign-off, copyright, and provenance requirements;
- supported versions and compatibility matrices;
- recent accepted and rejected work of the same type;
- organization or foundation rules that apply to the repository.

Record each controlling source, scope, branch or version, date checked, short
paraphrase, and any conflict.

Use this precedence:

1. law, regulation, contract, and confidentiality;
2. repository policy;
3. organization or foundation policy;
4. published project guidance and maintainer decisions;
5. conservative defaults.

Do not assume the newest file has authority. Do not assume silence permits or
prohibits AI. Ask before substantial work when policy remains ambiguous.
